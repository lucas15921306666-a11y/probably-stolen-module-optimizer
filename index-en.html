Search Settings

This is a 2D combinatorial optimization problem with adjacency effects; the optimizer automatically chooses Beam Search or multi-start stochastic + local search based on the target type.

With At-least or power hard targets, the optimizer first finds the minimum feasible module depth, then widens the search across alternative layouts at the same module count and runs fixed-count all-position replacement/reposition refinement. Compute budget expands the search frontier and candidate coverage; pure Maximize tasks still use multi-start stochastic search. Minimize module count requires at least one hard target.
